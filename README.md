# Rash Portfolio

A modern and responsive personal portfolio website designed to showcase my technical skills, software development projects, AI/ML work, research interests, academic journey, achievements, and professional experience.

This portfolio is built using **React, TypeScript, Vite, and Tailwind CSS**, with a focus on clean design, smooth interactions, responsive layouts, modern animations, and an engaging user experience.

## Getting Started

Follow the steps below to run the project locally.

### Clone the Repository

```bash
git clone https://github.com/therash08/Rash_portfolio.git
```

### Go to the Project Directory

```bash
cd Rash_portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

After running the command, Vite will start the local development server.

The website will normally be available at:

```text
http://localhost:5173
```

---

## Production Build

To create an optimized production build, run:

```bash
npm run build
```

The production files will be generated inside the:

```text
dist/
```

folder.

To preview the production version locally, run:

```bash
npm run preview
```
